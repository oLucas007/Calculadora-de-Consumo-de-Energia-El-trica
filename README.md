# Calculadora-de-Consumo-de-Energia-Eletrica
ajudar o usuário a estimar o consumo mensal de energia elétrica de um aparelho, utilizando informações simples como potência e tempo médio de uso diário.  Além do consumo em kWh, o programa também calcula uma estimativa do custo mensal da energia.

# linguagem
Python🐍

# Para calcular o consumo mensal, é utilizada a seguinte fórmula:

consumoMensal = (potencia ⚡ × horasDia ⏱️ × 30) / 1000

Para calcular o custo estimado:

custoMensal = consumoMensal × valorKwh

Neste projeto, foi utilizado o valor fixo de R$ 0,82 por kWh como exemplo. R💲

# Para executar o programa
O programa solicitará:

🔌 Nome do aparelho;
⚡ Potência em watts (W);
⏱️ Tempo médio de uso diário em horas.

Depois, serão apresentados:

📊 Consumo estimado em kWh/mês;
💰 Custo estimado em reais por mês.
